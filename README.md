# games-hub

A multi-game web app (starter) — Vite + React + Phaser 3.

This repo contains a small game hub and a playable Tic‑Tac‑Toe demo to get started.

Run locally:

1. git clone https://github.com/kowinslol/games-hub.git
2. cd games-hub
3. npm install
4. npm run dev
5. Open http://localhost:5173

What's included:
- Vite + React shell (game library and player area)
- Phaser 3 Tic‑Tac‑Toe scene (src/games/tictactoe)
- Styles and simple UI
